# Hi, I'm Sumit Gupta

Backend and platform engineer focused on distributed systems, integrations, identity, and multi-tenant products. I work mainly with Java, Spring Boot, TypeScript, GraphQL, Kafka, Redis, PostgreSQL, MongoDB, Docker, Kubernetes, and AWS.

I'm currently building multi-tenant education platform features at EduTrend while pursuing an M.S. in Computer Science at the University at Buffalo. Previously, I worked at miniOrange on enterprise SaaS applications across SSO/IAM, Shopify integrations, GraphQL APIs, cloud deployments, and production reliability.

- Multi-tenant systems with tenant isolation, RBAC, JWT auth, secure lifecycle operations, and observability
- Integration platforms using webhooks, API sync pipelines, retries, idempotency, Kafka, Redis, and third-party APIs
- Identity and access management with SAML 2.0, OAuth 2.0, OIDC, JWT, PKCE, SCIM, and enterprise IdP integrations
- Cloud delivery with Docker, Kubernetes, AWS, CI/CD, structured logging, and production debugging
