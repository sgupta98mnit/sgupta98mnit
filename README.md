## About Me

I build scalable, secure backend systems in Java/Spring Boot and TypeScript — event-driven services, enterprise SSO/IAM integrations, and multi-tenant platforms designed to run reliably in production.

- 🔭 **Currently:** Software Engineer at **EduTrend**, building multi-tenant education platform features.
- 🎓 **Studying:** M.S. in Computer Science at the **University at Buffalo**.
- 🏢 **Previously:** Senior Software Engineer at **miniOrange**, leading a 12-member team across SSO/IAM, Shopify integrations, and GraphQL APIs.
- ⚙️ **Focus areas:** distributed systems, event-driven architecture, enterprise identity, and production reliability.
